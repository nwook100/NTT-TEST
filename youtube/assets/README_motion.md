# Paper Tiger Files — motion graphics

Generated by `youtube/assets/motion_tool.py` (Python + Pillow + numpy → ffmpeg).
Every clip: **1920×1080, 30 fps, H.264 MP4, yuv420p, CRF 20, no audio**, 3–6 s (the logo sting is 2.6 s).
Full-frame clips have subtle film grain (refreshed every 3 frames), a light flicker and a vignette, on the channel
background (radial #1e2027 → #0d0e11), with red #d7263d and paper #f3ede2. Fonts: Liberation Sans/Serif, DejaVu Sans Mono.
All on-screen text is taken from the scripts, with the legal qualifiers kept ("according to the SEC", "according to the courts",
"prosecutors said", "never proven", "as reported by victims' groups"). No photos of any real person are used anywhere.

## How to use in CapCut
- **Chapter cards / key moments / date stamps**: drop on the main video track as full-screen shots. They fade in and out on their own, so a hard cut is fine; add a `whoosh`/`impact` SFX at the start (see the edit plans).
- **Lower thirds (`*_lowerthird_*`)**: rendered on pure black without grain. Put them on a track above the footage and set **Blend → Screen**: black disappears, the white text and red bar stay. (`lower_third(..., alpha_mov=True)` can also write a ProRes 4444 `.mov` with real transparency, ~14 MB each, not generated by default.)
- Turn off auto-captions under these clips so the same sentence is not shown twice.
- Where each clip goes: `youtube/edit_plan_ep01.md`, `youtube/edit_plan_ep02.md`.

## Regenerate / make new clips
```bash
pip install pillow numpy
python3 youtube/assets/motion_tool.py ep01            # or ep02 / all
python3 youtube/assets/motion_tool.py ep02 --only stamp   # only files whose name contains "stamp"
python3 youtube/assets/motion_tool.py all --list      # print the output paths only
```
Reusable functions (import `motion_tool`): `key_phrase`, `word_by_word`, `count_up` (also counts down; `end_red`, `glitch`),
`stamp`, `typewriter`, `chapter_card`, `lower_third`, `route_map` (lat/lon → schematic map), `logo_sting`.
Grain can be tuned with env vars `PTF_GRAIN` (default 4.0), `PTF_HOLD` (3), `PTF_LUMA` (0.25).
New episodes: add an `epNN_jobs()` list at the bottom of the file, same pattern.

Notes on wording:
- EP.01 `s12_wordbyword_plea_quote` shows "[UST]" in brackets, matching the court record and `card_06` (the script narration says "UST").
- EP.01 `s00_countup_40B` / `s04_countup_20pct` / `s13_countup_280000_korea` use "~"/"around"/"about" as in the script.
- EP.02 officials appear by rank only; Cho Hee-pal is never described as convicted.
