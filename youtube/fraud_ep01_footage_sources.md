## 0. 쓸 수 있는 것과 쓰면 안 되는 것

| ✅ 사용 가능 | ❌ 사용 금지 |
|---|---|
| Pexels, Pixabay, Mixkit, Coverr 무료 영상 (상업적 이용 가능, 출처 표기 불필요) | 다른 유튜버 영상 (ColdFusion, Coffeezilla 등) |
| **미국 정부 문서** (SEC 소장, 법무부 보도자료) → 미국 연방정부 저작물은 저작권이 없음 | 뉴스 방송 화면 (CNN, KBS, 블룸버그 등) |
| 위키미디어 공용(Wikimedia Commons)의 CC 라이선스 사진 → 라이선스 조건대로 출처 표기 | 언론사·통신사 사진 (AP, 로이터, 연합뉴스 등) |
| 직접 만든 그래프·인포그래픽 (PPT) | 권도형 인터뷰 영상 원본 |
| 직접 찍은 영상 (서울 거리, 아파트 야경 등. 얼굴 없이) | 트위터 화면 캡처를 그대로 쓰는 것 → 문구만 직접 타이핑해서 재현 |
| AI 생성 영상 (크레딧 필요) | 실존 인물을 닮게 만든 AI 영상 |

> 무료 사이트도 가끔 라이선스가 바뀝니다. 내려받을 때 각 클립의 라이선스 표시를 한 번 확인하세요.

## 2. 권도형 사진은 어떻게 하나?
- 언론사 사진은 **쓰지 마세요.**
- [Wikimedia Commons에서 "Do Kwon" 검색](https://commons.wikimedia.org/w/index.php?search=Do+Kwon)으로 CC 라이선스 사진이 있는지 확인하고, 있으면 라이선스대로 출처를 표기해서 사용합니다.
- 없으면 실루엣이나 이름 자막으로 처리합니다. 오히려 다큐 분위기에 잘 맞습니다.
