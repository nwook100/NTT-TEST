# EP.03 meta (zh-Hant)

## 標題

```
她暗中擁有一家銀行，再把它掏空：越南270億美元詐欺案
```

## 說明

```
一位房地產大亨，如何暗中掌控越南一家大型銀行90%以上的股份，又如何透過主要只存在於紙面上的公司轉走數十億美元？
張美蘭案：空殼公司、記滿現金的司機筆記本、被收買的檢查官員，以及在銀行櫃檯被推銷債券的35,000名存戶。

萬盛發集團（Van Thinh Phat）董事長張美蘭（Truong My Lan），被胡志明市法院認定為西貢商業銀行（SCB）超過91.5%股份的真正持有人。十年間，SCB向她的關係網絡發放了2,500多筆貸款。2024年4月，她被判犯有侵占304兆越南盾（約125億美元）、行賄及違反銀行業規定等罪，被判處死刑，並被命令返還約270億美元。在第二場審判中，她被判犯有詐騙35,824名債券持有人逾30兆越南盾的罪行。2025年，越南廢除了侵占罪的死刑。債券持有人至今仍在一點一點地獲得償付。
```
