# 채널 프로필 설명 + 언어 추가 (영어·한국어·일본어·중국어·스페인어)

## 어디에 넣나요
1. YouTube 스튜디오 → **맞춤설정(Customization) → 기본 정보(Basic info)**
2. **설명(Description)** 칸에 아래 *English* 문구를 붙여넣기 (채널 기본 언어 = 영어)
3. 같은 화면 아래 **"+ 언어 추가(Add language)"** 클릭
   - 원래 언어(Original language): **English**
   - 추가할 언어 5개: **Korean / Japanese / Chinese (Simplified) / Chinese (Traditional) / Spanish**
     (YouTube는 중국어를 간체·번체로 따로 받습니다. 둘 다 넣으면 중국 본토·대만·홍콩 시청자 모두에게 보입니다.)
   - 각 언어의 **이름(Name)** 칸: 모두 `Paper Tiger Files` 그대로 (브랜드 통일, 검색 일관성)
   - 각 언어의 **설명(Description)** 칸: 아래 해당 언어 문구 붙여넣기
4. 오른쪽 위 **게시(Publish)**

> 시청자의 YouTube 언어 설정에 맞춰 해당 언어 설명이 자동으로 보입니다.
> 기존 영어 설명에 있던 "72시간 만에" 표현은 실제 붕괴 기간(약 일주일)에 맞춰 "며칠 만에"로 고쳤습니다.
> 조희팔 편 제작 여부가 미정이라, 특정 사건을 예고하던 문장은 일반적인 문장으로 바꿨습니다.
