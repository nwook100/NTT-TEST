# 신성테크놀로지 홍보 모션그래픽

`index.html` 하나로 동작하는 45초짜리 홍보 모션그래픽입니다. 브라우저에서 열면 바로 재생되고,
`render.cjs`로 MP4 영상 파일을 뽑을 수 있습니다.

## 구성 (장면 순서)

| # | 장면 | 시간 | 내용 |
|---|------|------|------|
| 1 | 인트로 | 0–6s | 웨이퍼가 그려지며 회사 이름이 떠오름 |
| 2 | 소개 | 6–13s | "칩이 되기까지 수백 번의 이동" + 공정 흐름선 |
| 3 | 제품 | 13–27s | Magazine · Cassette · Ring · Pin Boat 선화가 순서대로 그려짐 |
| 4 | 강점 | 27–34s | 정밀 가공 · 소재 대응 · 맞춤 설계 |
| 5 | 위치 | 34–39.5s | 경기도 안산 + 영업 문의 |
| 6 | 마무리 | 39.5–45s | 회사 이름과 슬로건 |

## 문구 수정하기

`index.html`의 `<script>` 맨 위 `COPY` 객체만 고치면 됩니다. 특히 아래 두 줄은 실제 값으로 바꿔 주세요.

```js
phone: '[전화번호]',   // 예: 031-000-0000
email: '[이메일]',     // 예: sales@company.co.kr
```

장면 길이는 `SCENES` 배열의 `start`, `dur`(초)로 조정합니다. 한 장면을 늘리면 뒤 장면의 `start`와 `TOTAL`도 같이 옮겨야 합니다.

## 조작

- 화면 가운데 재생 버튼, 또는 `Space`
- `←` `→` 5초 이동, `1`–`6` 장면 바로 가기
- 아래 진행 막대를 끌어서 탐색

## MP4로 뽑기

```bash
npm i -D playwright
npx playwright install chromium
node motion/render.cjs motion/shinsung-motion.mp4 30
```

1920×1080, 30fps, H.264 MP4가 생성됩니다. ffmpeg가 PATH에 있어야 합니다.

## 3D 제품 모델

`3d/parts/` 의 three.js 모델(매거진·카세트·링·핀 보트)을 제품 장면(13~27초)에서 불러와 턴테이블처럼 돌려 보여 줍니다.
three.js(cdnjs)를 불러오지 못하는 환경에서는 예전 2D 선화 카드로 자동 대체됩니다. 자세한 내용은 `3d/README.md`.

## 동작 원리 (학습용 메모)

- 모든 움직임은 "현재 시각 t"를 받아 화면을 그리는 `render(t)` 함수 하나로 계산합니다.
  그래서 재생, 되감기, 장면 점프, 영상 캡처가 전부 같은 코드를 씁니다.
- `seg(t, 시작, 길이, 곡선)`이 시간을 0~1 진행도로 바꾸고, `rise()`가 그 값을 투명도와 위치로 옮깁니다.
- 제품 선화는 SVG `pathLength="1"` + `stroke-dashoffset`으로 "그려지는" 효과를 냅니다.
- 배경(웨이퍼, 공정선, 눈금자, 레이더 링)은 `<canvas>`에 매 프레임 다시 그립니다.
- 3D 제품은 별도 WebGL 캔버스(three.js)에 그리고, 카드 위치(픽셀)를 3D 좌표로 환산해 카드 안에 맞춥니다.
