# 안산 미니 CAD — 1년 로드맵

목표: **캐드 파일보다 가볍고, 우리 업무에 필요한 기능은 캐디안과 같은, AI로 그리는 CAD.**
진행 방식: 매주 기능 1~2개. 달마다 실제 업무 도면 1장을 이 프로그램으로 그려 보고 부족한 점을 다음 달 계획에 넣는다.

## 1분기 (1~3개월) — 기본 CAD 완성
- [x] 선·사각형·원·치수·문자, 스냅, 명령줄, 되돌리기 (v0.1)
- [x] DXF 저장 (R12), 한글 지원
- [x] DXF 불러오기: 폴리선, 블록, 치수, MTEXT, 한글 CP949/UTF-8 (v0.2)
- [ ] 레이어 창 (켜기/끄기, 색, 현재 레이어), 불러온 레이어·색 유지
- [ ] 선종류 (중심선, 숨은선), 선 두께
- [ ] 편집 1: 이동(M), 복사(CO), 회전(RO), 대칭(MI), 축척(SC)
- [ ] 편집 2: Trim(TR), Extend(EX), Offset(O)
- [ ] 편집 3: Fillet(F), Chamfer(CHA), 배열(AR)
- [ ] 스냅 추가: 교차점, 수직, 접선
- [ ] 속성 창: 선택한 객체의 좌표·반지름 숫자로 고치기

## 2분기 (4~6개월) — 업무 도면
- [ ] 치수 종류: 지름(Ø), 반지름(R), 각도, 공차(±)
- [ ] 도면 양식(표제란): 회사명, 도번, 재질, 척도, 작성자, 날짜
- [ ] 제품 생성기: 매거진, 웨이퍼 링, 핀보트 (카세트 고도화 포함)
- [ ] 해치(단면 빗금)
- [ ] 자체 파일 형식 `.mcad` — JSON 압축, 같은 도면 DXF 대비 크기 1/5 이하 목표
- [ ] PDF/PNG 내보내기 (견적서 첨부용)

## 3분기 (7~9개월) — AI 강화
- [ ] AI로 수정하기: "구멍을 전부 Ø10으로", "피치 6.35 → 5로"
- [ ] AI 도면 검토: 빠진 치수, 겹친 선 찾기
- [ ] 스케치·사진 → 도면 초안
- [ ] 고객 요구사항 문장 → 제품 생성기 수치 자동 입력 → 견적용 개략도

## 4분기 (10~12개월) — 현장 적용
- [ ] 큰 도면(객체 5만 개) 속도 개선
- [ ] 도면 공유 링크, 여러 사람 코멘트
- [ ] 부품 라이브러리(자주 쓰는 블록)
- [ ] DWG 직접 지원 여부 결정 (LibreDWG=GPL, ODA=유료 — 라이선스 검토 후)
- [ ] 사내 사용 매뉴얼, 1.0 출시

## DWG 전략
DWG는 오토데스크의 비공개 형식이다. 당분간 **캐디안/오토캐드에서 DXF로 저장하거나, 무료 ODA File Converter로 DWG→DXF 일괄 변환**해서 연다. 직접 지원은 4분기에 라이선스를 보고 결정한다.
