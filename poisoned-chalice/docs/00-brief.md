# 독이 든 성배 — 공통 기획 브리프 (모든 팀원 필독)

## 한 줄 컨셉
7시즌 연속 꼴찌, 5년간 감독 6명이 경질된 프로야구단 **반월 펠리컨스**(경기도 안산 반월 연고, 가상 구단)에
신임 감독으로 부임한다. 감독 자리는 "독이 든 성배". 구단주의 무리한 요구, 팬들의 분노, 선수단 사기 사이에서
버티며 한 시즌(16주) 안에 탈꼴찌·가을야구를 노리는 **모바일 텍스트 경영 시뮬레이션**.

## 플랫폼
- iOS / Android. HTML5 단일 페이지 게임(바닐라 JS) → Capacitor로 앱 패키징.
- 세로 화면, 한 손 조작, 1판 15~20분.

## 핵심 루프 (1주 = 1턴, 총 16주)
1. **훈련 선택**: 타격 특훈 / 투수 집중 / 수비 펑고 / 휴식·회복
2. **이벤트 카드**: 사건 1장, 선택지 2개(효과가 수치로 보임)
3. **경기 시작**: 이번 주 상대와 6경기 자동 시뮬레이션 → 스코어보드 결과
4. **구단주 메시지**: 주간 성적에 따라 신뢰도 변화
- 8주차: 올스타 브레이크 구단주 면담(특수 이벤트)
- 16주 종료 시 순위로 엔딩. 구단주 신뢰 0 → 즉시 경질 엔딩.

## 상태 값 (엔진 필드명)
| 필드 | 의미 | 범위 | 시작값 |
|---|---|---|---|
| trust | 구단주 신뢰 | 0–100 | 55 |
| fans | 팬 민심 | 0–100 | 30 |
| morale | 선수단 사기 | 0–100 | 40 |
| budget | 예산(억 원) | 0– | 30 |
| bat / pit / def | 타격·투수·수비 능력치 | 20–90 | 44 / 40 / 42 |
| boost | 이번 주 한정 집중력(전력 가산) | 주마다 0으로 초기화 | 0 |
| promise | "가을야구 공약" 플래그 | bool | false |
읽기 전용 파생값: week(1–16), rank(1–10), wins, losses

## 공식 (v0.1)
- 우리 전력 = (bat+pit+def)/3 + (morale−50)×0.2 + boost
- 상대 전력: 서울 블루윙즈 62, 광주 레드폭스 60, 인천 씨호크스 58, 대구 아이언즈 57, 수원 캐슬즈 56,
  부산 마린스타 55, 창원 스틸웨일 54, 대전 볼츠 52, 고양 스카이 50 (매주 ±1 랜덤 변동, 경기마다 ±3 노이즈)
- 경기 승률 p = 1 / (1 + e^(−(우리−상대)/11))
- 매주 10팀을 무작위 5쌍으로 짝지어 6경기씩.
- 훈련: 선택 능력치 +3(70 초과 시 +1), 사기 −2 / 휴식: 사기 +8
- 주간 신뢰 변화(6경기 중 승수 0~6): −7, −4, −2, +1, +4, +6, +8. 4주차부터 "성배의 독" −1/주 추가.
- 팬: (승수−3)×2, 사기: (승수−3)×2. 팬 ≤10이면 신뢰 추가 −3.
- 엔딩: 1위 기적 / 2–5위 가을야구·재계약 / 6–8위 탈꼴찌·유임 / 9위 신뢰 40 미만이면 경질 / 10위 경질.

## 톤
KBO 문화(트럭 시위, 치킨, 벤치클리어링, 구단주 낙하산, 외국인 투수, 우천취소, 2군 콜업)를 블랙코미디로.
실존 구단·선수·기업명은 쓰지 않는다. 구단주는 밉지만 귀여운 악역.

## 비주얼 방향
옛 야구장 수동식 스코어보드: 짙은 녹색 판, 분필색 글씨, 주황색 전구(신뢰/팬/사기 게이지), 꼴찌를 뜻하는 빨강.
