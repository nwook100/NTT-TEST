# 04. 밸런스 — 16주 시즌 몬테카를로 분석

- 도구: `node tools/simulate.mjs [판수=10000] [all|v01|rec] [seed]` (기본 시드 20261013, 전략별 1만 판)
- 공식: `00-brief.md` v0.1을 그대로 구현. 10팀 무작위 5쌍 × 6경기, 상대 전력 주간 ±1, 경기별 ±3 노이즈.
- 이벤트 카드 근사: 매주 신뢰 +1, 무작위 능력치 1개 +1. (8주차 구단주 면담·예산·공약은 시뮬 제외)
- "실패" = 시즌 중 경질 + 10위 + (9위 & 신뢰 40 미만).

플레이어 전략
| 코드 | 전략 | 의도 |
|---|---|---|
| a | 매주 4개 선택지 중 무작위 | "무작정 플레이" 기준선 |
| b | 항상 가장 낮은 능력치 훈련 | 사기 무시 |
| c | 사기 < 35면 휴식, 아니면 최저 능력치 훈련 | "좋은 전략" 기준선 |
| d | 항상 휴식 | 퇴화 전략(막아야 함) |

목표 체감: a 실패 50~60% / c 가을야구(1~5위) 25~35%, 1위 2~5% / d는 명확히 나빠야 함.

진단
1. **너무 어렵다.** 시작 전력 = 42 + (40−50)×0.2 = 40, 상대 평균 ≈ 56 → 첫 주 경기 승률 약 19%. 주당 1~2승 → 신뢰 −4/주 수준으로 12주차 전후 대량 경질.
2. **"항상 휴식"이 최적 전략(치명적).** 휴식 사기 +8 = 전력 +1.6, 훈련 +3 = 전력 +1.0 − 사기 비용 0.4 = +0.6. 휴식이 훈련의 약 2.7배 효율이고 상한(사기 100)까지 반복 가능 → 훈련 메뉴가 함정이 된다.
3. **어떤 능력치를 훈련하든 같다.** 전력이 단순 평균이므로 "약점 보완" 판단이 의미 없음 → 전략 a/b 차이가 전부 사기 관리에서만 나옴.
4. 1위는 0%. 서울(62)과의 격차를 16주 안에 메울 수 없음.

엔진 반영용 공식 요약(v0.2)
```

p = 1 / (1 + e^(−(우리−상대)/10))
훈련: 선택 능력치 +5 (해당 능력치 60 초과면 +2), 사기 −2
```

## 4. 추가 시스템 제안

### 4-1. 연승/연패 스트릭
- 주간 4승 이상 연속 2주 → "상승세": 다음 주 boost +2, 팬 +3. 3주 연속 시 구단주 메시지 특수 대사.
- 주간 2승 이하 연속 2주 → "연패 늪": 사기 −3 추가, 3주 연속 시 **트럭 시위 이벤트** 강제 발동(신뢰 −3 또는 예산 −3억 선택).
- 기대 효과: 현재 모델은 주차 간 상관이 약해 서사가 밋밋함. 스트릭은 "흐름"을 체감시키고 휴식 타이밍 판단(연패 끊기)에 의미를 준다. 밸런스 영향은 대칭이라 평균값을 크게 흔들지 않음(도입 시 재시뮬 권장).

### 4-2. 부상 (외국인 투수 · 주전 이탈)
- 매주 훈련 선택 시 부상 확률: 사기 < 30이면 15%, 그 외 5%. 부상 시 무작위 능력치 −4가 2~3주간 적용 후 복구.
- 휴식 주에는 부상 확률 0% + 진행 중 부상 1주 단축.
- "2군 콜업"(예산 −2억: 즉시 −4를 −2로 완화) / "진통제 투혼"(부상 무시, 다음 부상 확률 2배) 선택지.
- 기대 효과: 휴식에 사기 외 가치를 부여(v0.2에서 고사기 휴식은 +2뿐이라 보완), 예산 사용처 확보.

### 4-3. 트레이드 마감일 (11주차)
- 11주차 이벤트 대신 트레이드 시장 오픈: 예산을 써서 능력치 구매(예: 5억 → 최저 능력치 +4, 10억 → +8) 또는 유망주 팔고 예산 +8억·팬 −5.
- 9위 이하일 때만 "파이어세일" 선택지(능력치 −3, 예산 +10억, 신뢰 +3: 구단주는 돈을 좋아함).
- 기대 효과: 예산(30억)이 엔진에 있지만 현재 쓸 곳이 거의 없음 → 시즌 중반 의사결정 분기점. 가을야구 경쟁 중이면 올인, 가망 없으면 버티기 위한 신뢰 확보라는 블랙코미디 선택.
