# 돗자리 단속반 — UI/UX 설계서

> 대상: `games/seat-hog/game.html` (단일 HTML, 프로토타입 v0)
> 기준 화면: 폰 세로 360×640(CSS px, 브라우저 UI 제외) 최소 ~ 430×860, 데스크톱은 가운데 정렬 최대 폭 480px
> 이 문서는 설계안이며 `game.html`은 수정하지 않았습니다.

---

## 0. 현재 프로토타입 진단 (설계 출발점)

| 항목 | 현재 상태 | 문제 | 이 문서의 대응 |
|---|---|---|---|
| 화면 구성 | 한 화면에 제목·설명·HUD·격자·범례가 모두 상시 노출 | 360×640에서 격자(약 407px)+제목+범례로 세로 스크롤 발생, 플레이 중 시선 분산 | 화면을 분리(§1), 인게임에서는 제목·범례 숨김 |
| HUD | 시간·점수·콤보 3칸 동일 크기 + 민원 게이지 별도 줄 | 패배 조건인 민원 게이지가 가장 작고(10px), 콤보가 점수와 같은 비중 | 우선순위 재배치(§2) |
| 민원 위험 표현 | 그라데이션 색만 변함 | 색만으로 위험을 전달, 위험 구간 신호 없음 | 70% 이상 다중 신호(§2.4) |
| 입력 | `pointerdown` 즉시 판정 | 스크롤·손바닥 스침·연타가 곧바로 -150 오인 단속 | 탭 판정 규칙(§3.2) |
| 구분 | 파랑 vs 노랑 돗자리 + 쪽지/사람 이모지 | 색약 사용자는 줄무늬 색으로 구분 어려움, 범례도 색 견본만 | 모양·테두리·쪽지 형태로 이중 부호화(§5.1) |
| 일시정지 | 없음, 탭 전환 시에도 계속 진행 | 전화·알림에 판이 망가짐 | 일시정지 버튼 + 자동 일시정지(§2.6) |
| 사운드 | 항상 켜짐 | 공공장소에서 끌 방법 없음 | 사운드/진동 토글(§3.3) |
| 진행 구조 | 단일 판, 최고 기록만 저장 | 재방문 동기 약함 | 3스테이지·별점·잠금(§1.2) |

```
                                                     │  일시정지    │─────┘

```

- 화면 전환은 단일 HTML 안에서 `<section data-screen="title|select|game|result">` 를 하나만 보이게 토글합니다(라우팅 없음, 뒤로가기는 §1.6).
- 전환 애니메이션: 페이드 + 8px 위로 슬라이드 180ms. reduced-motion이면 즉시 전환(§5.3).
- 저장(localStorage, 모든 접근은 try/catch, 실패 시 기본값으로 정상 동작):
  - `seathog-progress` : `{"s1":{"stars":2,"best":8200}, "s2":{...}}`
  - `seathog-tutorial-done` : `"1"`
  - `seathog-settings` : `{"sound":true,"vibe":true}`
  - 기존 `seathog-best` 는 최초 실행 시 `s1.best` 로 이관

### 1.3 튜토리얼 (첫 판만, 3단계 말풍선)

조건: `seathog-tutorial-done` 이 없을 때 스테이지 1 시작 시 1회. 설정(⚙)에 "튜토리얼 다시 보기" 제공.
진행 방식: 실제 인게임 화면 위에 어두운 막(rgba(14,18,34,.72))을 깔고, **설명 대상만 구멍(스포트라이트)으로 밝힘**. 튜토리얼 동안 타이머·게이지 정지.

### 1.6 뒤로가기/이탈 처리
- 인게임에서 브라우저 뒤로가기·`visibilitychange(hidden)`·`blur` → 자동 일시정지. (`history.pushState`로 인게임 진입 시 상태 하나 쌓고 `popstate` 시 일시정지 시트 표시)
- 일시정지 시트에서 "그만두기" → 확인 없이 스테이지 선택으로(기록 미저장). 확인 다이얼로그는 만들지 않되, 버튼을 위험 색 + 맨 아래 배치로 오탭을 줄임.

## 2. 인게임 HUD 개선안

### 2.1 정보 우선순위

| 순위 | 정보 | 이유 | 표현 강도 |
|---|---|---|---|
| 1 | **민원 게이지** | 유일한 즉시 패배 조건. 현재는 가장 작음 | 전체 폭, 높이 16px, 70%↑ 다중 경고 |
| 2 | **남은 시간** | 생존 목표(시간까지 버티기) | 24px 숫자 + 원형/바 보조, 10초↓ 강조 |
| 3 | **점수** | 결과·별점 기준 | 24px 숫자, 중앙 |
| 4 | **콤보** | 동기 부여용, 판단에 필수 아님 | x1일 땐 흐리게, x2↑부터 강조 |
| 5 | 대기 관람객 수 | 게이지의 원인 설명 | 게이지 오른쪽 12px 텍스트 |
| 6 | 일시정지 | 상시 접근 가능해야 하지만 눈에 띌 필요 없음 | 좌상단 아이콘 44×44 |

### 2.2 레이아웃 (360×640 기준)

```

├────────────────────────────────┤
│  📝쪽지·짐 = 걷기   👤사람 = 그대로  │ ④ 미니 범례 32px (스테이지1만,
└────────────────────────────────┘   2·3에서는 숨김) + safe-area-bottom
```

세로 합계(360×640): 상단 48 + 게이지 28 + 간격 8×3 + 격자 407 + 범례 32 + 상하 패딩 24 ≈ **563px** → 640 안에 스크롤 없이 들어감. 높이가 600 미만이면 범례를 숨기고, 그래도 넘치면 격자 칸 크기를 `min(폭 기준, (가용높이-패딩)/5)`로 계산(최소 60px).

| 요소 | 위치 | 크기(px) | 비고 |
|---|---|---|---|
| 일시정지 버튼 | 좌상단 | 터치 44×44, 아이콘 20 | 반투명 원형 배경 |
| 남은 시간 | 상단 좌측 2열 | 숫자 24 / 라벨 11 | `tabular-nums`, 10초 이하 빨강+⏰ 아이콘+1초마다 확대 1.15 |
| 점수 | 상단 가운데 | 숫자 24(430폭 28) | 득점 시 +값이 점수 쪽으로 날아와 흡수(200ms) |
| 콤보 | 상단 우측 | 배지 56×32, 숫자 20 | §2.5 |
| 민원 게이지 | 상단 둘째 줄 전체 폭 | 바 높이 16, 라벨 12 | 25/50/70% 눈금선, %수치 텍스트 병기 |
| 대기 인원 | 게이지 우측 | 12 | 👥 아이콘 + "7명" |
| 격자 칸 | 중앙 | 360폭 71 / 390폭 78 / 430폭 88 | 데스크톱 최대 104 |
| 미니 범례 | 하단 | 높이 32, 13 | 스테이지 1에서만 |

데스크톱(≥768px 폭): 같은 세로 레이아웃을 최대 폭 480px로 중앙 배치. 남는 좌우 공간에 범례·조작법(키보드: 방향키 이동, Space/Enter 단속, P/Esc 일시정지)을 표시.

### 2.3 시간 표시
- 기본 `--ink`. 10초 이하: 빨강 + ⏰ 아이콘 추가 + 매초 1.15배 펄스(감속 모드는 펄스 없이 굵게/밑줄).
- 스크린리더: 30·10초 시점에만 `aria-live="polite"`로 "10초 남음" 안내(매초 읽지 않음).

### 2.4 민원 게이지 위험 상태 (70% 이상)

| 구간 | 바 | 아이콘/텍스트 | 화면 | 소리/진동 |
|---|---|---|---|---|
| 0–49% | 주황 단색 | 😐 "민원" | — | — |
| 50–69% | 주황→빨강 | 😠 "민원 증가" | — | — |
| **70–89% (위험)** | 빨강 + 사선 줄무늬 패턴 | **⚠ "위험" 배지** + % 굵게 | 격자 바깥 테두리 빨강 2px 비네트, 게이지 1.2s 주기 맥동 | 진입 순간 1회: 저음 경고음 2번 + `vibrate([60,40,60])` |
| **90–99% (임박)** | 빨강 + 줄무늬 이동 | ⚠ "곧 폭발!" | 비네트 4px, 맥동 0.6s | 진입 1회: `vibrate(150)`, 심장박동 사운드 루프(소리 켬일 때) |
| 100% | — | — | 결과 화면(실패) | 실패 사운드 + `vibrate([100,50,200])` |

- **색에만 의존하지 않음**: 위험 진입 시 ⚠ 아이콘, "위험" 텍스트, 줄무늬 패턴, 바 두께 변화(16→20px)가 함께 바뀜.
- 히스테리시스: 70% 진입 후 65% 미만으로 내려가야 위험 해제(경계에서 경고가 깜빡이는 것 방지). 경고 소리/진동은 구간 **진입 시 1회**만.
- 스크린리더: 70%·90% 진입 시 `aria-live="assertive"` "민원 위험, 70퍼센트".
- 게이지 요소: `role="meter" aria-valuemin=0 aria-valuemax=100 aria-valuenow=… aria-valuetext="민원 72퍼센트, 위험"`.

```
평상시  민원 😐 ██████▱▱▱▱▱▱▱▱▱▱  38%       👥 4명
위험    민원 ⚠위험 ▚▚▚▚▚▚▚▚▚▚▚▚▱▱▱  76%    👥 11명   (바 20px, 테두리 비네트)
임박    민원 ⚠곧 폭발! ▚▚▚▚▚▚▚▚▚▚▚▚▚▚▱ 93%  👥 15명
```

### 2.5 콤보 표시
현재 규칙: 선점 걷기 성공마다 +1(최대 x5), 오인 단속 시 x1로 초기화. (시간 경과 초기화 없음 — 유지 권장, 캐주얼 난이도에 맞음)

| 콤보 | 배지 | 연출 |
|---|---|---|
| x1 | 회색 테두리, 숫자 흐림(투명도 .5) | 없음 |
| x2–x3 | 주황 배경 + 🔥 1개 | 증가 시 배지 1.3배 → 1.0 (150ms) |
| x4 | 주황 배경 + 🔥🔥 | 동일 + 짧은 상승음 |
| x5 (MAX) | 빨강 배경 + "MAX" 텍스트 | 배지 테두리 빛, 탭한 칸에서 "+500 MAX" 팝업 크게(22px) |
| 끊김 | 배지가 회색으로 떨어지며 "콤보 끊김" 12px 0.6초 | 하강음 |

- 득점 팝업(`+300`)은 탭한 칸 위에 18px로 뜨고, 콤보 배수가 2 이상이면 `+300 (x3)` 형식으로 배수를 텍스트로 병기.

### 2.6 일시정지 버튼과 시트
- 위치: 좌상단(오른손 엄지가 격자를 누를 때 실수로 닿지 않는 쪽; 왼손잡이 옵션은 범위 밖).
- 크기: 터치 44×44, 시각 아이콘 20px(⏸ 두 막대 — 텍스트 라벨 "일시정지"는 aria-label).
- 자동 일시정지: `visibilitychange`, 창 `blur`, 뒤로가기.
- 재개 시 **3·2·1 카운트다운** 후 재개(갑자기 재개되어 실수 탭 방지).

## 3. 터치 UX

### 3.1 최소 터치 영역
- **모든 버튼·토글: 44×44px 이상**(WCAG 2.5.5/Apple HIG). 주 버튼 높이 56px.
- **격자 칸: 최소 60×60px**, 기본 71px(360폭). 칸 사이 8px 간격도 해당 칸의 터치 영역에 포함되지 않도록(간격 탭은 무시) — 경계 오탭이 옆 칸으로 들어가지 않게 함.
- 돗자리 그림은 칸 안 6% 인셋이지만, **판정은 칸 전체**(버튼 요소 전체)로.
- 화면 가장자리 16px 좌우 여백 유지 → 안드로이드 제스처 뒤로가기 영역과 격자가 겹치지 않음.
- CSS: `touch-action: manipulation`(더블탭 확대 방지), `-webkit-tap-highlight-color: transparent`, `overscroll-behavior: none`(당겨서 새로고침 방지), `user-select: none`(유지).

### 3.2 실수 탭 방지

| 규칙 | 내용 | 이유 |
|---|---|---|
| 탭 확정 시점 | `pointerdown`에서 눌림 표시(칸 0.94배), **`pointerup`이 같은 칸에서, 이동 10px 이하**일 때 판정 | 스크롤·문지르기·손바닥 스침으로 오인 단속되는 것 방지. 체감 지연은 ~80ms로 캐주얼 게임에 무리 없음 |
| 등장 직후 보호 | 새로 놓인 돗자리는 **250ms 동안 탭 무시**(벌점 없음, 판정 없음) | 선점을 걷은 칸에 관람객이 350ms 뒤 바로 앉는 구조라, 연타 시 방금 앉은 관람객을 치는 억울한 상황 방지 |
| 걷는 중 칸 | `cleared` 애니메이션 중인 칸은 입력 무시 | 중복 판정 방지 |
| 멀티터치 | 동시에 최대 2포인터까지만 판정, 3번째 이상 무시 | 손바닥/여러 손가락 접촉 오판 방지 |
| 오인 단속 완충 | 관람객 칸 탭 시 판정 전 **눌림 표시 단계에서 칸이 빨간 테두리+👤 아이콘 강조**(pointerdown 순간), 손가락을 칸 밖으로 끌어내 떼면 취소 | "아차" 하는 순간 취소할 기회 제공 |
| 카운트다운/전환 중 | 3·2·1, 일시정지 해제 카운트, 결과 화면 등장 직후 **500ms** 버튼 비활성 | 게임 중 연타가 결과 화면 "다시하기"로 새어 들어가는 것 방지 |
| 키보드 | 방향키로 칸 이동(로빙 tabindex), Enter/Space 단속, 키 반복(`e.repeat`) 무시 | 데스크톱 오입력 방지 |

### 3.3 피드백

**시각(항상)**: 성공 = 돗자리 말려 사라짐 + 초록 `+100` + 체크 ✓ 아이콘. 실패 = 칸 흔들림 + 빨강 `-150 실례!` + ✕ 아이콘 + 격자 흔들림. (텍스트·아이콘이 있어 색 없이도 결과 구분)

**사운드(on/off 토글)**
- 기본값: 켬. 단, 첫 사용자 상호작용 전에는 AudioContext를 만들지 않음(자동재생 정책).
- 토글 위치: 타이틀 하단, 일시정지 시트. 칩 형태 `🔊 소리 켬` / `🔇 소리 끔` — 아이콘과 텍스트가 함께 바뀜. `aria-pressed`.
- 소리 목록: 성공(콤보에 따라 음 높아짐), 오인 단속(저음 톱니파), 콤보 끊김, 위험 경고(70%), 임박 심장박동(90%), 성공 종료, 실패 종료. 볼륨은 현재 수준(gain .06) 유지.

**진동(선택적, `navigator.vibrate`)**
- 지원 여부 감지: `'vibrate' in navigator` 가 거짓이면(iOS Safari 등) 진동 토글 자체를 **숨김**.
- 기본값: 켬(지원 기기만). 토글 `📳 진동 켬/끔`, 설정에 저장.
- 패턴(짧게, 남용 금지):

| 이벤트 | 패턴(ms) |
|---|---|
| 선점 걷기 성공 | `15` (아주 짧은 틱) — x5 MAX 시 `[15,30,15]` |
| 오인 단속 | `[40,30,40]` |
| 민원 70% 진입 | `[60,40,60]` (1회) |
| 민원 90% 진입 | `150` (1회) |
| 게임 종료 | 성공 `[30,50,30,50,80]` / 실패 `[100,50,200]` |

- 모든 호출은 `try { navigator.vibrate?.(p) } catch {}` 로 감싸기. reduced-motion이어도 진동은 사용자 토글을 따름(별도).

## 4. 결과 화면

### 4.1 구성 요소(위→아래)
1. 결과 헤드라인: 성공 "축제 무사 개막!" / 실패 "민원 폭발…" (아이콘 🎆 / 💢 동반)
2. 별 1~3개 (순차 등장 300ms 간격, 각 별 아래 달성 조건 텍스트)
3. 점수(48px) + "새 최고 기록!" 배지 또는 "최고 8,200점"
4. 세부 통계: 걷어낸 돗자리 / 오인 단속 / 최고 콤보 / 최고 민원%
5. 칭호(카드 형태)
6. 버튼: [다음 스테이지 ▶] (주) / [다시하기] (보조) / 스테이지 목록(텍스트)

### 4.2 별 기준

| 별 | 조건 (스테이지 1 기준) | 스테이지 2 | 스테이지 3 |
|---|---|---|---|
| ★1 | 시간 끝까지 **버티기**(민원 100% 미도달) | 동일 | 동일 |
| ★2 | ★1 + 점수 **6,000점 이상** | 8,000 | 10,000 |
| ★3 | ★2 + 점수 **10,000점 이상** 그리고 **오인 단속 2회 이하** | 13,000 / 2회 | 16,000 / 1회 |

- 실패(민원 폭발)하면 점수와 무관하게 별 0개 → "다음 스테이지" 버튼은 이미 해금된 경우에만 활성.
- 별은 **최고치만 저장**(낮은 결과로 덮어쓰지 않음).
- 점수 기준값은 플레이테스트로 조정 전제(현재 프로토타입 칭호 구간 4,000/9,000/15,000과 정합하게 설정).

### 4.3 칭호
기존 프로토타입 칭호를 재사용하고 특수 칭호를 추가. 우선순위 위에서부터 첫 일치.

## 5. 접근성

### 5.1 색만으로 구분하지 않기 — 선점 vs 관람객

현재: 파랑 줄무늬(선점) vs 노랑 줄무늬(관람객) — 같은 사선 줄무늬라 색각 이상 시 구분 어려움. 아래 **5가지 단서 중 최소 3가지**가 항상 다르게.

| 단서 | 선점 돗자리 (걷어낼 것) | 관람객 돗자리 (그대로 둘 것) |
|---|---|---|
| 1. 내용물 아이콘 | 짐 이모지(🎒🧺🧳📦) — **사람 없음** | 사람 이모지(👵👨‍👩‍👧) — **사람 있음** |
| 2. 쪽지 형태 | **네모 종이 쪽지**, -4° 기울어짐, 위쪽에 테이프 조각, 손글씨 문구("맡아둔 자리") + 📝 | 쪽지 없음. 대신 **둥근 말풍선**(♪, 하트 등 감정)이 가끔 뜸 |
| 3. 테두리 | **점선** 테두리 2px (임시로 깔아둔 느낌) | **실선** 테두리 2px + 그림자(사람 무게감) |
| 4. 바닥 무늬 | **사선 줄무늬** | **체크(격자) 무늬** |
| 5. 하단 표시 | 없음 | 체류 시간 바(현재 `.age`) + 👤 작은 아이콘 |

```
  선점 (걷기)                     관람객 (두기)
 ┌ ─ ─ ─ ─ ─ ─ ┐                ┏━━━━━━━━━━━━┓
   ╔═📝맡아둔═╗                  ┃  ▦▦▦▦▦▦▦▦  ┃
 │ ╚═════════╝ │                ┃    👨‍👩‍👧     ┃
    ////🎒////                  ┃  ▦▦ ♪ ▦▦▦  ┃
 │  ///🧺/////  │                ┃ 👤▬▬▬▬▬▱▱  ┃
 └ ─ ─ ─ ─ ─ ─ ┘                ┗━━━━━━━━━━━━┛
 점선·네모쪽지·사선·짐            실선·쪽지없음·체크·사람·체류바
```

- 색 팔레트도 색각 이상에 강한 조합 유지: 선점 = 파랑(#3d7bd9), 관람객 = 노랑/황토(#c9a04a) → 파랑-노랑 축은 적록 색약에서도 구분됨. 대비는 배경 잔디(#1f3b2c) 대비 3:1 이상.
- 스테이지 2 "가짜 관람객"(인형): 사람 대신 🧸 + **네모 쪽지**가 있어, "쪽지 = 선점" 규칙 하나로 판단 가능하게 설계(색·형태 규칙 일관성).
- 범례(타이틀·스테이지1 하단)는 색 견본이 아니라 **실제 축소 돗자리 그림**(쪽지·테두리 포함)으로.
- 스크린리더: 칸 `aria-label` — "3행 2열, 선점 돗자리, 짐만 있음, 쪽지: 맡아둔 자리" / "3행 3열, 관람객 앉아 있음" / "3행 4열, 빈 잔디". 실제 게임 속도상 스크린리더 단독 플레이는 어렵다는 점을 인정하고, 설정의 "느린 모드"(등장 속도 50%, 민원 증가 50%)를 추가 권장(별 기록은 따로 표시).
- 글자: 본문 최소 14px(HUD 라벨만 11–12px), 대비 4.5:1 이상. `--muted`(#9aa3c0) on `--night`(#141a2e) ≈ 7:1 로 충분.
- 포커스: 모든 인터랙티브 요소 `:focus-visible` 3px `--lantern` 외곽선(현재 유지).

### 5.2 소리 단서의 대체
- 모든 소리 이벤트에는 시각 대응이 있음(위 표). 소리를 꺼도 정보 손실 없음.
- 진동 미지원 기기에서도 동일.

### 5.3 reduced-motion (`prefers-reduced-motion: reduce`)
현재 프로토타입은 모든 애니메이션을 일괄 `none` 처리 → 득점 팝업이 사라지지 않고 남거나(`forwards` 미적용), 걷어내는 피드백이 사라지는 문제가 있음. **움직임은 줄이되 상태 변화 정보는 남기는** 방향으로:

| 요소 | 기본 | reduced-motion |
|---|---|---|
| 화면 전환 | 페이드+슬라이드 180ms | 즉시 전환(또는 페이드만 100ms) |
| 청사초롱 흔들림 | 3s 무한 회전 | 정지 |
| 돗자리 등장 | 0.6→1 확대 | 페이드 120ms만 |
| 돗자리 걷기 | 축소+회전 | 페이드아웃 150ms + ✓ 아이콘 표시 |
| 득점 팝업 | 위로 떠오름 | 제자리에서 600ms 표시 후 사라짐(타이머로 제거) |
| 오인 단속 흔들림 | 격자 좌우 흔들림 | 흔들림 없음, 칸 테두리 빨강 + ✕ 400ms |
| 민원 위험 맥동 | 게이지/비네트 맥동 | 정지 상태로 굵은 테두리+⚠ 고정 |
| 콤보 배지 튐 | 1.3배 튐 | 숫자만 교체 |
| 별 등장 | 순차 튀어오름 | 한 번에 표시 |
| 스포트라이트(튜토리얼) | 맥동 | 고정 테두리 |

- 게임 안 설정에서도 "움직임 줄이기" 토글을 제공하고, 기본값은 OS 설정을 따름.
- 번쩍임: 어떤 효과도 초당 3회 이상 깜빡이지 않음(임박 맥동 0.6s 주기 ≈ 1.7Hz로 기준 이하).

## 6. 구현 메모 (개발 참고, 우선순위 순)

1. 화면 섹션 분리 + 인게임 중 제목/설명/범례 숨김 → 360×640 스크롤 제거
2. 입력 판정 `pointerup` 확정 + 등장 직후 250ms 보호 + `touch-action: manipulation`
3. 민원 게이지 확대 + 70/90% 다중 경고 + 히스테리시스
4. 선점/관람객 이중 부호화(점선/실선, 사선/체크, 네모 쪽지)
5. 일시정지 버튼 + `visibilitychange` 자동 일시정지 + 재개 카운트다운
6. 사운드/진동 토글 + `seathog-settings` 저장
7. 스테이지 데이터 테이블화(`{id, name, sec, spawnMul, lifeMul, comboMax, stars:[...]}`) + 진행 저장
8. 튜토리얼 스포트라이트 3단계
9. 결과 화면 별/칭호/팁
10. reduced-motion 세분화
