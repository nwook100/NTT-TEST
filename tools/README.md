# 영업부 불량 관리 시스템 (defect-management.html)

반도체 부품(magazine / cassette / ring / pin boat) 영업부에서 고객 불량(불량)을
**접수 → 원인분석 → 조치 → 완료** 흐름으로 관리하기 위한 단일 HTML 도구입니다.

## 무엇인가요?

- `defect-management.html` **파일 하나**로 동작하는 불량 관리 프로그램입니다.
- 설치가 필요 없고, 인터넷 연결 없이도 **오프라인**으로 완전히 동작합니다.
- 외부 서버/라이브러리를 전혀 사용하지 않습니다 (순수 HTML + CSS + JavaScript).

## 여는 방법

1. `defect-management.html` 파일을 **더블클릭**합니다.
2. 기본 웹브라우저(크롬, 엣지 등)에서 화면이 열립니다.
3. 처음 열면 이해를 돕기 위한 **샘플 데이터 5건**이 자동으로 들어가 있습니다.
   - 실제로 쓸 때는 상단의 `전체 삭제` 버튼으로 비우고 직접 등록하거나,
     `샘플 데이터 초기화` 버튼으로 샘플을 다시 불러올 수 있습니다.

## 주요 기능

- **대시보드 요약 카드**: 전체 건수 / 처리중 / 완료 / 이번달 접수
- **불량 등록·수정·삭제**: 접수번호(`YYYYMMDD-NNN`)는 자동 생성됩니다.
- **상태 추적**: 접수 / 분석중 / 조치중 / 완료 (색상 배지)
- **필터 & 검색**: 상태·제품구분·고객사 필터, 불량내용/조치내용/고객사 검색
- **통계**: 제품구분별 / 불량유형별 / 상태별 막대 그래프, 고객사별 불량 건수 순위
- **상세 보기**: 문제(불량내용) → 원인(발생원인) → 조치(조치내용) 흐름을 한눈에 확인
- **엑셀 내보내기(CSV)** / **CSV 가져오기**
- **인쇄**: 목록과 상세를 깔끔하게 인쇄 (버튼·입력창은 인쇄되지 않음)

## 데이터는 어디에 저장되나요?

- 데이터는 **그 브라우저 안(localStorage)** 에 저장됩니다.
- 별도 저장 버튼 없이, 등록/수정하면 자동으로 저장됩니다.
- 브라우저를 껐다 켜도 데이터는 유지됩니다.

## 백업 방법 (중요)

- 상단의 **`엑셀 내보내기(CSV)`** 버튼으로 현재 목록을 CSV 파일로 내려받을 수 있습니다.
  - 한글이 깨지지 않도록 UTF-8 BOM 을 넣어 두었으므로 엑셀에서 바로 열립니다.
- 다시 불러오려면 **`CSV 가져오기`** 버튼을 사용합니다.
  - 가져올 때 **병합(기존에 추가)** 또는 **교체(기존 삭제 후 대체)** 를 선택할 수 있습니다.
- **정기적으로 CSV 로 백업해 두는 것을 권장합니다.**

## 한계 (꼭 알아두세요)

- 데이터는 **사용한 PC·브라우저 안에만** 저장됩니다.
  - 다른 PC나 다른 브라우저에서는 데이터가 보이지 않습니다.
  - 브라우저 데이터(캐시/기록)를 완전 삭제하면 데이터도 사라질 수 있습니다 → CSV 백업 필수.
- 여러 명이 **실시간으로 함께** 보고 수정하는 **팀 공유**는 이 파일만으로는 불가능합니다.
  - 팀 공유가 필요하면 별도 서버 구축 또는 구글시트 연동 등 추가 개발이 필요합니다.
  - 임시로는 한 사람이 CSV 로 내보내 공유하고, 받은 사람이 CSV 가져오기로 보는 방식이 가능합니다.
