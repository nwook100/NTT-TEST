# 하이닉스 시리얼 본호 중복 관리 (구글 시트 버전)

구글 시트를 DB로 쓰는 시리얼 등록/중복 차단 웹앱입니다.

## 바코드 형식 (18자리)
```
BX3812  260630  B  02051
고정번호 날짜    구분 본호
(6)     YYMMDD  (1)  (5)
```
- 구분: `A` = 노멀, `B` = 비드
- 본호는 **날짜가 바뀌면 00001부터 다시 시작**하고, **A(노멀)와 B(비드)는 본호를 따로** 매깁니다.
- **중복 판정 = 같은 날짜 + 같은 구분(A/B) 안의 본호**. `BX3812260630B02051` 등록 후:
  - `BX3812260630B02051` → ⛔ **중복** (같은 날짜, 같은 B, 같은 본호)
  - `BX3812260630A02051` → ✅ 정상 (A와 B는 따로)
  - `BX3812260701B02051` → ✅ 정상 (날짜가 다름)
- 자릿수·날짜·구분·고정번호가 틀린 바코드(스캔 오류 등)는 **형식 오류**로 거절합니다.

여러 PC·작업자가 같은 시트를 공유하며, 동시에 같은 번호를 등록해도 **한 건만** 들어갑니다(서버 잠금).

## 기능
| 탭 | 설명 |
|---|---|
| 등록 / 검사 | 바코드 스캔 후 Enter → 고정번호/날짜/구분/본호로 나눠 표시. 중복·형식오류면 빨간 경고 + 경고음, 기존 등록 정보(바코드·LOT·작업자·일시·시트 행) 표시 |
| 연속 발번 | 고정번호·날짜·A/B 선택 → **그 날짜·구분의 마지막 본호 다음부터** N개 발번 (새 날짜는 00001부터). 이미 쓴 본호는 건너뜀 |
| 일괄 검사 | 엑셀에서 복사한 목록 붙여넣기 → 신규 / 기존 중복 / 목록 안 중복 / 형식 오류 판정, 신규만 등록 |
| 이력 조회 | 바코드·본호·LOT·작업자로 검색 |

- 상단에 **가장 최근 등록한 날짜·구분의 마지막 본호**가 표시됩니다.
- 시트에 직접 입력한 본호 중복도 빨간색으로 표시되고, 시트 메뉴 **[시리얼 관리 > 시트 내 중복 검사]** 로 중복·형식오류를 찾을 수 있습니다.
- 막힌 시도(중복·형식오류)는 **[중복차단로그]** 시트에 사유와 함께 남습니다.

## 설정 (`Code.gs` 맨 위)
| 항목 | 기본값 | 설명 |
|---|---|---|
| `ALLOWED_CODES` | `['BX3812']` | 허용 고정번호. 다른 고정번호가 생기면 `['BX3812', 'BX4000']` 처럼 추가 |
| `DUP_SCOPE` | `'DATE_TYPE_SERIAL'` | `DATE_TYPE_SERIAL`: 같은 날짜 + 같은 A/B 안에서 본호 중복 금지 (현재 규칙) / `DATE_SERIAL`: A/B가 번호를 같이 쓰는 경우 / `CODE_SERIAL`: 날짜 상관없이 본호 중복 금지 |

## 설치 (약 5분)
1. 구글 드라이브에서 **새 구글 시트** 만들기 (예: `하이닉스 시리얼 DB`)
2. 메뉴 **확장 프로그램 > Apps Script** 열기
3. `Code.gs` 내용을 전부 지우고 이 폴더의 `Code.gs` 를 붙여넣기
4. 왼쪽 **파일 + > HTML** → 이름을 `Index` 로 만들고 `Index.html` 내용 붙여넣기
5. (선택) 톱니바퀴 **프로젝트 설정 > "appsscript.json" 표시** 체크 후 이 폴더의 `appsscript.json` 붙여넣기 (시간대 서울)
6. 상단 함수 선택에서 `setup` 선택 → **실행** → 권한 허용
   → `시리얼DB`, `중복차단로그` 시트가 만들어집니다.
7. **배포 > 새 배포 > 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **Google 계정이 있는 모든 사용자** (회사 워크스페이스면 "도메인 내 모든 사용자")
8. 나온 **웹 앱 URL** 을 작업 PC 브라우저 즐겨찾기에 등록 → 끝

> 코드를 수정한 뒤에는 **배포 > 배포 관리 > 편집(연필) > 버전: 새 버전** 으로 다시 배포해야 반영됩니다.

## 운영 팁
- 잘못 등록한 번호는 시트 `시리얼DB` 에서 그 행을 삭제하면 다시 쓸 수 있습니다.
- 시트 공유는 **보기 권한**만 주고, 등록은 웹앱으로만 하면 실수로 지워지는 일을 막을 수 있습니다.
  (웹앱은 "실행 사용자: 나" 권한으로 기록하므로 작업자에게 편집 권한이 없어도 됩니다)
- 구글 시트 파일 > 버전 기록으로 언제든 이전 상태를 복원할 수 있습니다.
- 수만 건까지는 무리 없이 동작합니다. 수십만 건이 넘어가면 연도별로 시트를 나누는 것을 권장합니다.
