# 하이닉스 시리얼 본호 관리 - 업무 규칙 (변경 시 반드시 지킬 것)

## 바코드 형식 (18자리)
`BX3812` `260630` `B` `02051` = 고정번호(6) + 날짜 YYMMDD(6) + 구분(1) + 본호(5)
- 고정번호: 현재 `BX3812` (추가 시 `Code.gs` 의 `ALLOWED_CODES`)
- 구분: `A` = 노멀, `B` = 비드

## 본호 규칙 (사용자 확인 완료)
- 날짜가 바뀌면 본호는 00001부터 다시 시작한다. 99999까지 가는 일은 없다.
- A(노멀)와 B(비드)는 본호를 **따로** 매긴다.
- 따라서 중복 판정 단위 = **고정번호 + 날짜 + 구분(A/B) + 본호** (`DUP_SCOPE = 'DATE_TYPE_SERIAL'`)
  - 0630 B02051 등록 후: 0630 B02051 → 중복 / 0630 A02051 → 정상 / 0701 B02051 → 정상

## 구조
- 구글 시트가 DB (`시리얼DB`, `중복차단로그` 시트), Apps Script 웹앱(`Code.gs` + `Index.html`)
- 등록은 반드시 `LockService` 잠금 안에서 처리 (여러 PC 동시 등록 대비)
- 사용자는 개발자가 아닌 영업 담당자: 화면 문구와 안내는 한국어로 쉽게
