# 공대장부 — 제품 기획서 (1달 출시 계획)

작성일: 2026-10-19 · 목표 출시일: 2026-11-19 (와우포레버 레이드 오픈 12-09 이전)

## 1. 한 줄 정의

> 길드 레이드에서 **누가 왔고, 누가 뭘 먹었고, 포인트가 몇 점인지**를 링크 하나로 길드원 전체가 보는 한국어 모바일 장부.

채팅은 디스코드에 둔다. 공대장부는 디스코드가 못 하는 **기록과 정산**만 맡는다.

## 1-1. 두 가지 공대 모드

| | 정규공대 | 단기공대 (골팟) |
|---|---|---|
| 누가 | 길드원 | 길드원 + 외부 참여자 (닉네임만) |
| 분배 | 포인트로 아이템 가져감 | 아이템을 골드로 팔아 N분의 1 |
| 계산 | 참석 기본점 + 보스당 점수 − 사용 포인트 | 총 판매 − 공대장 수수료 % → 인원수로 나눔 (자투리는 공대장) |
| 결과 전달 | 디스코드 채널 자동 전송, 길드 채팅용 한 줄 | 디스코드 자동 전송, **와우 공격대 채팅용 정산 문구 + 1인별 귓속말 명령** (한 줄 255자 제한에 맞춰 분할, 한 줄씩 복사) |

와우 안으로 직접 메시지를 보내는 API는 없다. 그래서 앱이 와우 채팅 규격에 맞는 문구를 만들고, 공대장이 게임 채팅창에 붙여넣는다. 이 "복사 → 붙여넣기" 한 번이 지금 길드들이 엑셀 보고 손으로 타이핑하는 5분을 대신한다.

## 2. 지금 길드들이 쓰는 것과 왜 불편한가

| 지금 쓰는 방법 | 불편한 점 |
|---|---|
| 엑셀 / 구글 시트 | 공대장만 수정, 길드원은 폰으로 보기 어려움, 수식 깨짐 |
| 디스코드 채널에 글로 남김 | 흘러가서 지난주 기록을 못 찾음, 합산 불가 |
| 인게임 DKP 애드온 (CEPGP, Gargul 등) | PC 접속 중에만 보임, 영어, 설치·설정 어려움, 길드원 전체 공유 안 됨 |
| 영어권 DKP 웹사이트 | 한국어 없음, 디자인 오래됨, 와우포레버 미지원 |

공통 문제: **길드원은 자기 포인트를 물어봐야 알고, 분배 결과를 믿지 못한다.** 길드 분쟁의 대부분이 여기서 난다.

## 3. 차별화 다섯 가지

1. **링크 하나로 공유** — 공대장이 초대 링크를 디스코드에 올리면 길드원은 설치 없이 바로 본다. 가입 장벽이 0이다.
2. **길드원이 자기 포인트를 직접 본다** — 공대장에게 묻지 않는다. 투명성 자체가 기능이다.
3. **폰에서 레이드 중에 입력** — 보스 잡고 아이템 나오면 공대장이 폰으로 10초 안에 분배 기록. PC 애드온은 못 하는 일이다.
4. **한국어, 한국 길드 문화 기준** — 탱·힐·딜 집계, 참석률, "몰먹" 기록. 번역 앱이 아니라 처음부터 한국 길드용이다.
5. **와우포레버 출시 타이밍** — 11월 5일 모든 길드가 포인트 0에서 시작한다. 첫 레이드(12월 9일) 전에 자리 잡은 장부가 그 길드의 장부가 된다.

## 4. 상품성을 만드는 장치 (사람이 계속 쓰게 하는 것)

- **공대장의 이유**: 분쟁이 줄고, 분배 설명을 안 해도 된다. 공대장 한 명만 설득하면 길드 전체가 들어온다.
- **길드원의 이유**: 내 포인트와 참석률이 보인다. 다음 아이템을 언제 받을지 가늠이 된다.
- **퍼지는 경로**: 길드원이 다른 길드에 가도 "저기선 공대장부 썼는데"가 된다. 초대 링크가 곧 마케팅이다.
- **신뢰 장치**: 분배 기록은 수정 시 이력이 남는다. 포인트는 계산식이 공개된다.
- **첫 경험**: 샘플 데이터로 열자마자 "이런 거구나"가 보인다. 빈 화면으로 시작하지 않는다.

## 5. 수익 모델 (출시 후 2~3개월 뒤)

- 기본: 무료. 길드 1개, 길드원 40명까지.
- 길드 프리미엄 (월 3,000~5,000원, 공대장 1명만 결제): 길드 여러 개, 분배 이력 내보내기, 포인트 규칙 템플릿, 레이드 알림 푸시.
- 원칙: 길드원에게는 절대 돈을 받지 않는다. 받는 사람은 공대장 한 명이다.

## 5-1. 다른 앱과의 연계 (디스코드는 필수)

원칙: 공대장부는 "기록"을 맡고, 알림·대화·표는 길드가 이미 쓰는 앱으로 흘려보낸다.

### 지금 동작하는 것 (서버 없이)
| 연계 | 무엇이 되나 | 어떻게 |
|---|---|---|
| **디스코드 채널** | 레이드 마감 시 참석자·분배·포인트 요약이 채널에 자동으로 올라감. 포인트 현황도 버튼 하나로 전송 | 채널 웹훅 URL을 공대장 탭에 붙여넣기 |
| 카카오톡·디스코드 앱 | 레이드 결과나 현황을 텍스트로 공유 (아이폰 공유 시트 → 카톡 선택) | 공유 버튼 |
| 엑셀·구글 시트 | 포인트 현황, 분배 내역을 CSV로 내려받아 열기 | CSV 버튼 |
| 다른 기기 | JSON 백업 내려받기·복원 | 공대장 탭 연동 섹션 |

### 1~2주차에 붙일 것 (백엔드 생기면)
| 연계 | 무엇이 되나 |
|---|---|
| **디스코드 로그인** | 길드원이 디스코드 계정으로 바로 입장. 닉네임·아바타 자동 |
| **디스코드 봇** | 채널에서 `/포인트`, `/참석 오늘` 같은 명령으로 조회·입력. 앱을 안 열어도 됨 |
| **디스코드 서버 멤버 불러오기** | 길드 디스코드 역할(공대원)을 가진 사람을 길드원으로 한 번에 등록 |
| 구글 캘린더 | 다음 레이드 일정을 길드원 캘린더에 넣기 |
| 웹푸시 | 레이드 30분 전, 분배 결과 알림 (iOS 16.4 이상 PWA) |

### 와우 게임 데이터 끌어오기 (컴퓨터에서)

와우는 애드온이 외부로 데이터를 직접 보내는 것을 막아둔다 (네트워크 API 없음). 그래서 "자동으로 앱에 들어오는" 길은 네 가지 중 하나를 거친다.

| 경로 | 무엇을 가져오나 | 자동화 정도 | 현실성 |
|---|---|---|---|
| **A. 애드온 → 내보내기 문자열** | 공격대 명단, 보스 킬, 누가 뭘 먹었는지 | 공대장이 게임 안에서 `/공대장부` 입력 → 문자열 복사 → 앱에 붙여넣기 | **가장 현실적.** 특성 공유 문자열과 같은 방식. 2~3주차 |
| B. SavedVariables 파일 감시 | 애드온이 저장한 기록 파일 (`WTF/` 폴더) | 맥/PC에 작은 도우미 프로그램을 깔면 로그아웃·`/reload` 시점에 자동 업로드 | 완전 자동이지만 설치 부담. A가 자리 잡은 뒤 |
| C. 블리자드 공식 API | 캐릭터 정보, 길드 명단, 경매장 시세 | 로그인 한 번이면 자동 | 레이드 중 분배는 못 가져옴. 와우포레버 지원 여부 미확인 |
| D. Warcraft Logs | 전투 로그에서 참석자·보스 킬 | 로그 올리면 참석 체크 자동 완성 | 로그 올리는 길드에 한정. 참석 자동화용으로 좋음 |

순서: A(애드온 문자열)로 참석·분배 입력을 없애고 → D로 참석 체크를 자동화하고 → C는 포레버 API가 열리면 붙인다.

### 출시 후 검토
| 연계 | 메모 |
|---|---|
| 노션·구글 시트 자동 동기화 | 길드가 이미 시트를 쓰면 양방향 동기화 |
| 노션·구글 시트 자동 동기화 | 길드가 이미 시트를 쓰면 양방향 동기화 |
| 카카오톡 채널 알림 | 디스코드 안 쓰는 캐주얼 길드용. 비용 발생 |

## 7. 역할 분담

**과장님이 하실 일 (개발 아님, 더 중요한 일)**
- 와우포레버 출시 주에 길드 2~3곳 공대장 섭외. "무료로 써보고 욕해달라."
- 실제 레이드 1회를 이 앱으로 돌리고 막힌 순간을 메모 (그게 다음 주 작업 목록).
- 포인트 규칙을 한국 길드들이 실제로 어떻게 쓰는지 정리 (기본점, 보스점, 지각 감점, 몰먹 비용).
- 이름 최종 결정과 아이콘 취향 결정.

**제가 할 일**
- 매주 위 체크리스트를 코드로 만들고, 빌드·검증해서 푸시.
- 매주 월요일 "이번 주 뭘 만들고 뭘 확인해야 하는지" 한 장으로 정리.

## 9. 하지 않을 것

- 채팅, 음성 (디스코드가 한다)
- 경매장·캐릭터 자동 조회 (블리자드 API 포레버 지원 미확인)
- 길드 모집 게시판 (사람 모으기 문제가 다르다)
- 안드로이드 네이티브 (PWA로 충분, 수요 생기면 Capacitor로 같이 포장)

## 10. 실행 방법

```bash
npm install
npm run dev        # http://localhost:3000/#/ledger
npm run build && npm run preview
```

- `#/` 클랜 홈, `#/ledger` 공대장부
- 코드 위치: `dkp/` (types, calc, store, screens)
